Системный инженер и аналитик данных с 15-летним опытом. Автоматизирую сбор данных, проектирую базы данных и аналитические инструменты.

- Проектирование ЭОМ, электрощитов (ЩУРН, ШР, ШО, ВРУ, 1-3ф), 0,4-10кВ, ТП.

### 🗃️ **Системная аналитика и анализ данных** 
- Инструменты: Python (pandas, numpy, scipy), SQL, Plotly.
- Подходы: EDA, ELT, работа с временными рядами, выявление аномалий, валидация данных.
- Решения: Интерактивные дашборды, системный аудит активов.
- Формализация ТЗ, описание бизнес-логики и алгоритмов, проектирование прототипов.
